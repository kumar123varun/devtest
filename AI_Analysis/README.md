# AI analysis

Written by the **AWS TnC Change Monitor** - one file per analysed service: `<Service>_AI_Analysis.md`.

Each file shows how the AI reached its findings: what it was given (the change, the AWS documentation passage, the
sections of the assessment), the instructions it followed (word for word), its checklist answers with the quoted
evidence and whether the kit found the quote, the vote over several attempts, the independent review of High
findings, the severity rule from the Trust and Control framework, and the reasoning behind the decision.

Files arrive through pull requests from the kit and are rewritten on every run - Git keeps the history.
